# dsh-soul

让 DSH 在持续交流中形成更稳定、更有连续性的个体记忆与人格。

## 能做什么

- **记住重要经历**：从反复出现的诉求、被纠正的回答、工具失败与修正等行为痕迹中，选择性留下经历。
- **自然遗忘**：记忆会随时间逐渐淡去；经常被想起的经历会更稳定，偶尔发生的事情不会永久占据上下文。
- **需要时想起过去**：根据当前对话记录必要信息，而不是每次都把整段历史塞进上下文。
- **形成并修正自我理解**：根据长期经历逐步形成对自身倾向的假设，同时保留反例、允许怀疑和撤回。
- **保持连续身份**：人格可以由ai修改，人格的修改将会被记录。
- **主人可控**：可以填写初始人格、查看人格历史、调整记忆与人格功能，并决定哪些核心认识值得保留。
- **工作区隔离**：不同工作区各自保存经历；人格身份可以保持连续。

dsh-soul 不是完整聊天记录备份，也不是把所有内容永久保存的 RAG。它更接近一种有选择、会遗忘、能够修正自己的长期记忆。

## 使用方式

安装并启用后，在 DSH 的插件设置中填写初始人格。之后正常对话即可：插件会根据互动中的行为痕迹记录经历，并在相关时刻让 DSH 想起过去。

插件也提供主动记忆和回忆能力。你可以直接要求 DSH 记住一件重要的事，或让它回想与当前话题有关的经历。

## 安装


将 `dsh-soul-0.1.0.tgz` 安装到 DSH 所使用的 profile，然后把 `dsh-soul` 加入该 profile 的 bundle 列表并重启 DSH。具体安装命令取决于你的 DSH 配置方式；源码仓库和 Release 中都提供了完整包文件。

安装后打开插件设置页即可配置：

- 是否记录新经历
- 是否自动回忆经历
- 记忆衰减速度与召回数量
- 是否允许人格自我修订
- 是否生成仅供主人查看的人格摘要

## 数据与隐私

记忆数据保存在本机，不会由本插件自动上传。人格身份数据与工作区经历数据分开保存；删除对应数据库即可清除本地记忆。

关闭插件后，它不会继续监听对话、记录经历或注入记忆。已有的 DSH 聊天记录不属于插件管理范围。
